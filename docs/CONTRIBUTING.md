# Contributing

1. Keep all prices in integer paise in domain data.
2. Preserve `source`, `lastUpdatedAt`, and `dataQuality` for every price, seat, and showtime record.
3. Never add scraping, private API reverse engineering, or fabricated availability.
4. Run `npm run test`, `npm run build:api`, and `npm run build` before opening a change.
5. Add a decision record for changes that affect provider terms, ranking, privacy, or data retention.
